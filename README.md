# 💊 PillMate — 영양제·약 복용 알람

컴퓨터 앞에서 영양제·처방약 복용 시간을 놓치지 않게 해주는 1인용 Windows 데스크톱 앱입니다.
휴대폰이 멀리 있거나 충전 중이어도, 지금 보고 있는 모니터 맨 위에 알람이 뜹니다. 데이터는 모두 내 PC에만 저장됩니다.

> 복용 순서 추천은 참고용 정보이며 의사·약사의 지시가 우선합니다.

## 설치
1. `dist\PillMate-Setup-1.0.0.exe`를 실행합니다. (만드는 방법은 아래 '개발')
2. 코드 서명이 없어 **"Windows의 PC 보호"** 창이 뜨면 **추가 정보 → 실행**을 누릅니다.
3. 설치가 끝나면 바탕화면·시작 메뉴의 **PillMate**로 실행합니다. 이후 Windows를 켤 때 작업표시줄 트레이에 자동으로 뜹니다(설정에서 끌 수 있음).

### 제품 검색을 쓰려면 (선택)
- [식품안전나라](https://www.foodsafetykorea.go.kr/) 오픈API에서 **건강기능식품 품목제조 신고사항 현황(I0030)** 인증키를 신청합니다.
- 설치한 앱: `%APPDATA%\PillMate\.env` 파일에 `FOODSAFETY_API_KEY=발급받은키` 한 줄을 넣고 앱을 다시 켭니다. [설정] → **키 파일 폴더 열기**로 폴더를 열 수 있습니다.
- `.env` 파일은 메모장이나 VS Code로 여세요. (보안 프로그램 AnySign이 `.env`를 자기 파일로 착각해 암호를 물을 수 있습니다 — 입력하지 말고 닫으세요.)
- 키가 없어도 영양제를 직접 입력해 쓸 수 있습니다.

## 주요 기능
- **알람**: Windows 알림 + 모든 창 위에 뜨는 알람 창 + 소리. [먹었어요]/[N분 뒤 다시]/[건너뛰기]를 누를 때까지 남아 있고, 응답이 없으면 정해진 간격으로 다시 알립니다. PC가 꺼져 있거나 절전 중이었다면 켜자마자 "N시간 지남"으로 알려줍니다.
- **오늘 복용**: 오늘 먹을 영양제·처방약을 시간순으로 보여주고 직접 체크할 수 있습니다.
- **영양제**: 직접 입력하거나 식품안전나라에서 검색해 채웁니다. **복용 시점 추천**은 성분 규칙(`rules/timing-rules.json`)과 제품 라벨을 보고 기상 직후·아침·점심·저녁·취침 전 중 하나를 추천하고, 함께 먹으면 안 좋은 조합(예: 철분↔칼슘)을 경고합니다.
- **처방약**: 약봉투대로 식전·식후 N분, 먹는 때, 처방 일수를 입력하면 기간 동안만 알람이 울립니다. 앱이 처방 시점을 바꾸지 않습니다.
- **기록**: 최근 7일/30일 복용률, 날짜별 막대, 연속 완료일, 제품별 복용률.
- **설정**: 기상·식사·취침 시간으로 알람 시간을 계산합니다. 알람 소리·다시 알림 간격·자동 실행도 여기서 바꿉니다.

## 참고
- 창의 X를 눌러도 꺼지지 않고 트레이로 숨습니다. 완전히 끄려면 트레이 아이콘 우클릭 → **종료**.
- 복용 기록·설정은 `%APPDATA%\PillMate\pillmate.db`에 저장되며, 앱을 지워도 남습니다.

## 개발
Node.js 24 이상이 필요합니다. 자세한 구조와 규칙은 [CLAUDE.md](CLAUDE.md)를 보세요.

```bash
npm install          # 의존성 설치
npm run dev          # 개발 모드 실행
npm test             # 단위 테스트
npm run build:win    # 설치 파일 만들기 → dist\PillMate-Setup-<버전>.exe
```

개발 모드는 프로젝트 폴더의 `.env`를 읽습니다(`.env.example` 참고). 개발 모드와 설치한 앱은 같은 데이터(`%APPDATA%\PillMate`)를 쓰므로 동시에 켤 수 없습니다.

## 예전 프로토타입
`supplement_reminder.pyw`(Python/tkinter)와 `data.json`은 처음 만든 시제품으로, 동작 참고용으로만 남겨 두었습니다. PillMate는 이 데이터를 읽지 않습니다.
