# 💊 영양제 알림 (Supplement Reminder)

컴퓨터를 쓰는 동안 영양제 복용 시간을 놓치지 않게 해주는 Windows 데스크톱 앱입니다.
휴대폰이 충전 중이거나 멀리 있어도, 지금 보고 있는 모니터 위에 알림이 뜹니다.

## 실행
`supplement_reminder.pyw`를 더블클릭하세요. Python 3만 있으면 되고, 추가로 설치할 패키지는 없습니다.

## 주요 기능
- **사라지지 않는 알림창**: 정해진 시간이 되면 모든 창 위에 알림이 뜹니다. [먹었어요]를 누를 때까지 화면 맨 위에 계속 남아 있고, 1분마다 소리가 납니다.
- **다시 알림 / 건너뛰기**: 지금 먹기 어려우면 N분 뒤에 다시 알려줍니다.
- **놓친 알림 처리**: 알림 시간에 컴퓨터가 꺼져 있었다면, 켜자마자 "N시간 지남"으로 알려줍니다.
- **오늘 탭**: 오늘 먹을 영양제, 복용 상태, 다음 알림 시간을 보여줍니다.
- **영양제 관리**: 영양제를 추가·수정·삭제하고, 하루 여러 번 복용 시간도 설정할 수 있습니다(예: `08:30, 21:00`).
- **기록**: 최근 14일 복용률과 연속 복용 일수를 보여줍니다.
- **자동 실행**: [설정]에서 켜면 Windows를 시작할 때 작업표시줄에 최소화된 상태로 자동 실행됩니다.

## 참고
- 창의 X를 눌러도 프로그램은 종료되지 않고 작업표시줄로 최소화됩니다. 완전히 끄려면 [설정] → 프로그램 종료를 누르세요.
- 프로그램은 하나만 실행됩니다. 이미 실행 중일 때 다시 더블클릭하면 기존 창이 앞으로 나옵니다.
- 데이터는 같은 폴더의 `data.json`에 저장됩니다.
