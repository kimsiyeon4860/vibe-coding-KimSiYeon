# 💊 PillMate — 영양제·약 복용 알람 (정적 웹 앱)

PC 앞에서 영양제·처방약 복용 시간을 놓치지 않게 해 주는 **브라우저 웹 앱**입니다.
설치 없이 브라우저에서 열고, **탭을 열어 두면** 복용 시간에 화면 위 알람·브라우저 알림·소리로 알려 줍니다.
데이터는 서버 없이 **내 브라우저에만** 저장됩니다.

- **데모:** https://아이디.github.io/vibe-coding-이름/ ← GitHub Pages 주소로 바꿀 것
- 권장 브라우저: 최신 Chrome / Edge (PC)

> 복용 순서 추천은 참고용 정보이며 의사·약사의 지시가 우선합니다.

## 주요 기능
| 탭 | 기능 |
|---|---|
| **오늘 복용** | 오늘 먹을 영양제·처방약을 시간순으로, 먹었어요/건너뛰기/되돌리기. **생활 기록** 버튼(일어났어요·○○ 먹어요·안 먹어요·잘게요)을 누르면 그 시각에 맞춰 알람이 울림 |
| **영양제** | 직접 입력 또는 **제품 검색**(식품안전나라 건강기능식품 + 공공데이터포털 일반의약품). **복용 시점 추천**: 성분 규칙과 라벨을 보고 기상 직후·아침·점심·저녁 식후·취침 전 중 추천, 함께 먹으면 안 좋은 조합(철분↔칼슘 등) 경고 |
| **처방약** | 약봉투대로 식전·식후 N분·먹는 때·처방 일수 입력 → 기간 동안만 알람. 앱이 처방 시점을 바꾸지 않음 |
| **기록** | 최근 7일/30일 복용률, 날짜별 막대, 연속 완료일, 제품별 복용률 |
| **설정** | 기상·식사·취침 시간, 평소 먹는 식사, 생활 기록 방식(클릭 기록/고정 시간), 알람 소리·다시 알림, 알림 권한, 검색 API 키, 데이터 백업 |

### 알람 동작
- 시간이 되면 **페이지 위 알람 창 + 브라우저 알림(허용 시) + 소리 + 탭 제목 깜빡임**. 응답이 없으면 정해진 간격으로 다시 알림.
- 식사를 '클릭 기록'으로 두면, 기록이 없을 때 알람 대신 **"점심 드셨어요?"** 를 묻고, **안 먹어요**를 누르면 영양제는 다음 식사로 옮겨 알림 (처방약은 옮기지 않고 약사 지시대로 안내).
- 탭을 닫아 두었던 동안의 알람은 다시 열면 모아서 보여 줌.

### 웹판의 한계
- **탭이 열려 있어야** 알람이 울립니다 (백그라운드 탭은 확인 주기가 1분 정도로 느려질 수 있음). 다른 창을 보고 있어도 알 수 있도록 [설정 → 알림·소리 켜기]를 눌러 두세요.
- 데이터는 이 브라우저에만 있으므로 사이트 데이터를 지우면 사라집니다. [설정 → 데이터 백업]으로 가끔 내려받아 두세요.
- 같은 브라우저에서는 탭 하나에서만 열립니다 (기록 덮어쓰기 방지).

### 제품 검색 API 키
- 식품안전나라(건강기능식품): 기본으로 공개 **견본 키**(검색 결과 최대 5건)가 들어 있어 바로 써 볼 수 있습니다. 인증키를 받으면 [설정 → 제품 검색 API 키]에 넣으세요.
- 공공데이터포털(일반의약품, 약국 비타민제 등): '식품의약품안전처_의약품 제품 허가정보' 활용신청 후 받은 **일반 인증키**를 설정에 넣으세요.
- 키는 이 브라우저(localStorage)에만 저장되고, 검색할 때 해당 공공기관 서버로만 전송됩니다.

## 개발
Node.js 24 이상. 구조·규칙은 [CLAUDE.md](CLAUDE.md) 참고.

```bash
npm install
npm run dev:web      # 웹판 개발 서버
npm run build:web    # 웹판 빌드 → dist-web/ (GitHub Pages)
npm test             # 단위 테스트 (Vitest)
```

`main`에 push하면 GitHub Actions(`.github/workflows/pages.yml`)가 테스트 → 빌드 → GitHub Pages 배포를 합니다.

### 구조
- `src/core/` — 플랫폼 공통: DB(SQL·마이그레이션), 오늘 목록, 알람·확인 판단 엔진, 공공데이터 검색, 화면 요청 처리
- `src/shared/` — 순수 함수: 시간·복용일 계산, 추천, 규칙, 통계, 입력 검사
- `src/renderer/` — React 화면 (웹판·데스크톱판 공통)
- `src/web/` + `web/` — **웹판**: sql.js(브라우저용 SQLite) + IndexedDB 저장, 페이지 안 알람
- `src/main/`, `src/preload/` — 데스크톱판(Electron, 부록)
- `rules/timing-rules.json` — 성분별 복용 시점 규칙 (근거 수준·출처 포함)

## 부록: 데스크톱판 (Windows, Electron)
같은 핵심 로직을 쓰는 Windows 앱도 함께 있습니다. 트레이 상주·항상 위 알람 창·Windows 시작 시 자동 실행을 지원합니다.

```bash
npm run dev          # 데스크톱판 개발 실행
npm run build:win    # 설치 파일 → dist/PillMate-Setup-<버전>.exe
```

데스크톱판은 프로젝트 폴더(설치 앱은 `%APPDATA%\PillMate`)의 `.env`에서 키를 읽습니다 (`.env.example` 참고).
